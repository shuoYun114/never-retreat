# Never Retreat client

This directory is the standalone static client. Serve it with the bundled static server:

```bash
PORT=18081 node serve.js
```

…or upload it to any web host (Nginx/Caddy/static hosting).

## Server address

`js/35_server_config.js` is empty by default, which means the address is derived automatically:

- client and server on the same origin → that origin is used;
- client on 18081 → the same host on port **18080** (works for LAN and public deployments).

Only set it explicitly when the game server lives on a different host or domain:

```js
window.STEEL_FRONT_SERVER='https://api.example.com';
```

When the page is served over HTTPS this address must be HTTPS too, otherwise the browser blocks both
`fetch` and the WebSocket as mixed content.

## Generated file

`js/13c_attach_rules.js` is generated by `server/tools/gen_weapon_meta.js` and must not be edited by hand —
it carries the attachment-compatibility rule that the server enforces. Regenerate with `npm run gen`
inside `server/` after changing weapon stats.
